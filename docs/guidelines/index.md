# Guidelines

This page (and subpages) will provide a set of guidelines that should be followed within the Betfair Rebuild project.

## How to read the guidelines?

The guidelines section of the wiki is divided by responsability (application store, connected/presentational components, applicational services, backend for frontend, etc). However, such guidelines are also cross-referenced from pages which are more oriented to a given language / library (e.g: typescript) or a code style for a tool (e.g: React / React Native).

## How to contribute with new guidelines?

You can use the [template](template.md) for new guidelines and add a brief description, code examples on good or bad code usage and link it when appropriate.
