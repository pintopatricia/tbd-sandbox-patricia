A package that handles TBD redux store logic, used by web and native applications.

## Redux store

Redux is a state container for JavaScript apps, often called a Redux store. It stores the whole state of the app in an immutable object tree. The only way to change the state inside it is to dispatch an action on it.

## Store workgroup

### How to contribute

- Create issue on [TBD repo](https://github.com/Flutter-Global/tbd/issues) with the tbd-store label
- Workgroup members will have the first discussions on the issue (to check if it makes sense, to check if the issue has enough detail, etc...)
- Workgroup members will use the meetings to prioritize those issues, discuss them, and assign a person to create US(s) to address them.
